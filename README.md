# TealSuite (ティール スイート)

Windows 用の小さなアプリのセットです。インストールは不要で、フォルダを好きな場所に置くだけで使えます。

![Teal Hub](screenshots/TealHub.png)

| アプリ | できること |
|---|---|
| **Teal Hub** — アプリ管理 | ほかのアプリの起動・終了、アプリごとの設定 (ショートカット・常駐・スタートアップ)、アップデート |
| **Teal Pass** — パスワード管理 | パスワードを作って安全に保存 (このPC・このユーザーでしか読めません)。安全チェック・お気に入り・ブラウザーの CSV 読み込み |
| **Teal Memo** — メモ | シンプルなメモ帳。ピン留め・#タグ・ゴミ箱・.txt の読み書き |
| **Teal Clip** — コピー履歴 | コピーした文字の履歴をいつでも呼び出し (Ctrl + Shift + V)。検索・定型文・記録しない設定 |
| **Teal Volume** — 音量操作 | アプリごとの音量をすばやく変更 (Alt + V)。音量のプリセット・まとめてミュート |
| **Teal Wallet** — サブスク＆買い物リスト | サブスクの合計金額・次の支払い日・見直し候補をひと目で。買い物リスト (「牛乳 2 198円」で追加)・欲しいもの・月の予算 |
| **Teal Plan** — タスク＆予定 | 「明日15時 歯医者」「明日 15:00-16:00 歯医者 @駅前」と書くだけで登録。今日の予定とやること、カレンダーでドラッグして予定を作成。小タスクは一覧の中で進められます |

動作環境: Windows 10 / 11 (.NET Framework 4.5 以上。Windows に最初から入っています)

## 1.10.0 で増えたこと — Teal Tasks は「Teal Plan」になりました

Teal Tasks に予定 (スケジュール) を加えて、名前を **Teal Plan (タスク＆予定)** に変えました。アイコンも新しくなりました。
1.9.x からアップデートすると、タスクのデータ・ショートカット・常駐・スタートアップの設定はそのまま Teal Plan に引き継がれます
(古い Teal Tasks は消え、Teal Hub の一覧にも 2 つ並びません。Teal Hub に 1 回だけ「Teal Tasks は Teal Plan になりました」と出ます)。

- **小タスクが一覧の中で使える** … タスクの左の ▸ (または →) で、小タスクがすぐ下に並びます。タスクの行には「1/3」のように進み具合を表示。
  Space で完了、Tab か「＋小タスク」で追加、F2 で名前の変更、Delete で削除、Alt+↑↓ で並べ替え。「すべて開く」「すべて閉じる」(Ctrl+Shift+→ / ←)。開いていたタスクは次に起動したときも開いたままです
- **予定** … カレンダーの空いた所をダブルクリックするか、ドラッグでなぞると予定ができます (Ctrl+E でも)。予定をドラッグで移動、下の端で長さを変更 (15 分きざみ)。
  終日・何日かにわたる予定、場所、メモ、色、くり返し、お知らせをつけられます
- **書くだけで予定** … `明日 15:00-16:00 歯医者 @駅前`、`11/3-11/5 出張`、`10/30 終日 健康診断` のように、時刻の範囲・@場所・日付の範囲・終日のどれかがあれば予定になります (なければ今までどおりタスク)
- **今日** … 左に今日の予定の時間割、右にやることの一覧。**一覧** … 「タスク」「予定」(日ごとの予定表)「すべて」を切り替え。カレンダーは「タスクだけ」「予定だけ」にも絞れます

### アプリどうしの連携 (1.10.0)

- **Teal Hub の「今日」** … 今日と期限切れのタスク、今日の予定、これから 7 日の支払い、無料期間のおわり、予算の残り、ピン留めのメモを 1 つの画面に。
  ダブルクリックでそのアプリのその項目が開きます。ほかのアプリでデータが変わると自動で表示し直します。
  通知領域のアイコンには「今日のタスク 3件 / 支払い 1件」のように件数を出します (右クリック →「今日の件数を通知領域に出す」でオン・オフ)
- **まとめて検索** … Teal Hub の検索欄で、Teal Memo・Teal Plan・Teal Wallet と Teal Pass のサイト名を一度に探せます (アプリごとに分けて表示)。
  Teal Pass はロック中でもサイト名だけ探せます。ID・パスワード・メモ・URL は検索に出ません。Teal Clip のコピー履歴も出ません
- **Teal Pass の「サイト名を検索に出す」** … はじめはオン。サイト名だけの一覧を、このパソコンのこのユーザーだけが読めるように暗号化して保存します。オフにすると一覧を消します
- **Teal Plan のカレンダーに Teal Wallet の支払い日** … 💳「Netflix 1,490円」、⚠「○○ 無料期間おわり」のように出ます。読むだけで、ダブルクリックで Teal Wallet が開きます
  (Teal Plan の「設定」→「Teal Wallet の支払い日をカレンダーに出す」で消せます)
- **共通の #タグ** … Teal Memo と Teal Plan で「#」と打つと、両方で使ったタグを候補に出します。Teal Hub で `#買い物` と検索すると両方の項目が出ます

## Teal Wallet — サブスク＆買い物リスト (1.9.0。1.7.0〜1.8.0 は Teal Sub)

動画・音楽・クラウドなど、毎月や毎年お金がかかっているサービスと、ふだんの買い物をまとめて管理します。

### 買い物リスト (1.9.0)

上の入力欄に書いて Enter を押すだけで追加できます。「、」で区切ると何品かまとめて入ります。

| 書き方の例 | 追加される内容 |
|---|---|
| `牛乳 2 198円` | 牛乳・2 個・1 個 ¥198 (売り場は「乳製品・卵」と推測) |
| `卵 1パック 228` | 卵・1 パック・¥228 |
| `トマト3個` | トマト・3 個 |
| `ティッシュ #日用品` | 売り場「日用品」 |
| `にんじん、玉ねぎ、豆腐` | 3 品まとめて |

数字だけのときは 100 未満を数、100 以上を値段とみなします (「円」「¥」をつけると確実です)。値段や売り場を書かなかったときは、前に買ったときの記録から埋めます。

- **リストを何個でも** … 「スーパー」「ドラッグストア」「100円ショップ」など。Ctrl+PageUp / PageDown で切り替え
- **売り場ごとに並ぶ** … 野菜・果物 → 肉・魚 → … の順 (お店を回る順)。売り場は名前から自動で推測し、自分で変えられます
- **チェック** … Space かクリックでカゴに入れると、下の「カゴに入れた」に移ります
- **予想と実際の合計** … 右側に予想の合計・まだの分・カゴの中の分。「買い物を終える…」(Ctrl+Enter) でレシートの合計を入れると、履歴と今月の支出に残ります
- **よく買うもの・履歴から追加** … よく買うものは入力欄の下にボタンで出ます。「履歴から…」(Ctrl+H) で前に買ったものをまとめて追加
- **チェック済みを消す** (Ctrl+Delete) … 支出に残さずにカゴの中だけ消します
- **テキストでコピー** (Ctrl+Shift+C) … LINE やメモに貼れる形 (売り場ごと、カゴの中は ✓)
- **欲しいもの** … 目標の値段と優先度 (高・中・低) をつけて記録。今の値段が目標以下になると「買いどき」。買ったら (Ctrl+B) 支出に残ります。「買い物リストに入れる」もできます
- **月の予算** … 「設定」で買い物の月の予算を決めると、残りを表示。ダッシュボードに「今月の買い物」と「サブスク＋買い物」の合計が出ます


- **ダッシュボード** … 月あたり・1 年あたりの合計、次の支払い日、カテゴリ別の内訳
- **見直し候補** … 使う頻度・最後に使った日・1 回あたりの金額・同じカテゴリの重なりから点数をつけ、やめると年にいくら浮くかを表示
- **お知らせ** … 更新日と無料期間の終わりを 3 日前から (設定で変更可)
- **解約ガイド** … 一般的な解約の手順と、自分で登録した解約ページを開くボタン (解約の操作そのものはしません)
- **支払い予定** (1.8.0) … これから 12 か月、どの月にいくら払うかと、支払い方法ごとの金額。月の予算を決めると、超えていないかも表示
- 月払い・年払い・週払い・○か月ごと、無料期間、解約予定 / 解約済み、料金の変更の記録、CSV の書き出し・読み込み、バックアップ (JSON)

## Teal Plan — タスク＆予定 (1.10.0。1.7.0〜1.9.x は Teal Tasks)

上の入力欄に日本語で書いて Enter を押すだけで、期限・時刻・優先度・かかる時間・タグ・くり返しを読み取って登録します。
時刻の範囲・@場所・日付の範囲・「終日」・先頭の「予定:」のどれかがあると、タスクではなく予定になります (1.10.0)。

| 書き方の例 | 登録される内容 |
|---|---|
| `明日15時 歯医者 #病院` | タスク: 明日 15:00・タグ「病院」 |
| `金曜までにレポート提出 重要 2時間` | タスク: 金曜まで・優先度 高・2 時間 |
| `毎週水曜 ジム 1時間半` | タスク: 毎週水曜・1 時間 30 分 |
| `3時に電話` | タスク: 今日 15:00 (1〜6 時は午後とみなします) |
| `平日 9時 朝会` | タスク: 月〜金の 9:00 にくり返し (1.8.0) |
| `毎年 12/1 年賀状の準備` | タスク: 毎年 12/1 (1.8.0) |
| `明日 15:00-16:00 歯医者 @駅前` | 予定: 明日 15:00〜16:00・場所「駅前」(1.10.0) |
| `11/3-11/5 出張` | 予定: 11/3〜11/5 の終日 (1.10.0) |
| `10/30 終日 健康診断` | 予定: 10/30 の終日 (1.10.0) |

- **今日** … 左に今日の予定の時間割、右に期限切れと今日のタスクを「おすすめ順」(期限の近さ・優先度・かかる時間から) に並べます
- **カレンダー** … 月・週・日。空いた所をダブルクリック / ドラッグで予定を追加、ドラッグで移動、下の端で長さを変更。「すべて表示」「タスクだけ」「予定だけ」
- **一覧** … 「タスク」「予定」(日ごとの予定表)「すべて」。小タスクは ▸ で開いて、その場で完了・追加・名前の変更・並べ替え・削除
- **予定** … 終日・何日かにわたる予定、場所、メモ、色 (7 色)、くり返し (毎日・平日・毎週・毎月・毎年、終わりの日も)、お知らせ (始まる時刻〜1 日前)。
  くり返しの予定は「この回だけ」と「すべての回」を選んで変更・削除できます
- **お知らせ** … 時刻つきのタスクは 15 分前、その日のタスクは朝にまとめて、予定は決めた時間の前に
- くり返し (毎日・平日・毎週・毎月・毎年)、検索、統計、CSV 書き出し (タスクと予定)、Ctrl+Z で元に戻す
- 「その他 ▾」(1.8.0) … テンプレートから追加、まとめて追加 (1 行に 1 件)、複製、古い完了タスクの整理

| キー | 一覧・今日での操作 |
|---|---|
| → / ← | 小タスクを開く・閉じる (開いているときは小タスクへ移る / タスクに戻る) |
| Space | 完了 / 戻す (タスクでも小タスクでも) |
| Tab | 小タスクを追加 (入力中の Tab / Enter で確定して次へ、Esc でやめる) |
| F2 | 小タスクの名前を変える (タスクなら編集画面) |
| Alt + ↑ / ↓ | 小タスクの並べ替え |
| Delete | 削除 (小タスクのあるタスクは確認が出ます) |
| Ctrl + Shift + → / ← | すべて開く / すべて閉じる |
| Ctrl + E / Ctrl + N | 予定を追加 / タスクを追加 |
| Ctrl + 1〜4 | 今日・カレンダー・一覧・統計 |

## アプリごとの設定 (1.6.0)

Teal Hub の各カードにある「⚙ 設定」を押すと、画面がそのアプリの設定に切り替わります (「← 戻る」で一覧へ)。

- **ショートカット** … すべて Teal Hub が受け付けます。アプリが起動していなくても、押せば起動します
- **常駐** … オンにすると、× で閉じても通知領域に残ります (初期設定は Teal Clip・Teal Wallet・Teal Plan がオン)
- **スタートアップ** … Windows の起動時に自動で起動します (常駐がオンのアプリだけ選べます)

## ダウンロード

**[Releases](https://github.com/RrioK2065/TealSuite/releases/latest)** から `TealSuite-x.y.z.zip` をダウンロードします。

1. zip を右クリック →「プロパティ」→「ブロックの解除」にチェック →「OK」
2. zip を展開して、`TealSuite` フォルダを好きな場所 (ドキュメントなど) に置く
3. `TealHub.exe` を開く

### 「Windows によって PC が保護されました」と出たとき

署名のない新しいアプリなので、初めて開くときに SmartScreen の画面が出ることがあります。
「詳細情報」→「実行」で開けます。心配なときは、Releases にある `.sha256` の値とダウンロードしたファイルの値
(PowerShell で `Get-FileHash TealSuite-x.y.z.zip`) が同じか確かめてください。

## アップデート

1.5.0 からは、Teal Hub が新しいバージョンを 1 日 1 回確認し、見つかると画面にお知らせを出します。
「今すぐアップデート」を押すとダウンロードして確認画面が出るので、そこで「アップデート」を押せば入れ替わります (データはそのまま残ります)。

![アップデートのお知らせ](screenshots/TealHub_update.png)

- すぐ確認する: 「アップデート ▾」→「更新を確認」
- 自動の確認をやめる: 「アップデート ▾」→「自動で更新を確認する (1 日 1 回)」のチェックを外す
- 手動で入れる: Releases の `TealSuite-update-x.y.z.tealupdate` をダブルクリック
- 1.6.0 から 1.7.0 にすると、Teal Sub (今の Teal Wallet) と Teal Tasks (今の Teal Plan) が Teal Hub の一覧に自動で加わります。
- 1.8.0 から 1.9.0 にすると、Teal Sub が Teal Wallet に置き換わり、データと設定はそのまま引き継がれます (古いデータのフォルダ `%APPDATA%\TealSuite\TealSub` も念のため残します)。
- 1.9.x から 1.10.0 にすると、Teal Tasks が Teal Plan に置き換わり、データと設定はそのまま引き継がれます (古いデータのフォルダ `%APPDATA%\TealSuite\TealTasks` も念のため残します)。
- 1.8.0 にしたあとは、Teal Hub に「更新内容を見る」のお知らせが 1 回出ます (「その他 ▾」→「更新内容を見る…」でいつでも見られます)。
- 1.4.0 を使っている場合は、まだ自動のお知らせがないので、1.5.0 の `.tealupdate` を手動で一度入れてください。
- 1.3 以前を使っている場合は、一度だけ zip の中身でフォルダを上書きしてください。

詳しい使い方は zip に入っている `README.txt` を、変更点は [CHANGELOG.md](CHANGELOG.md) をご覧ください。

## データの保存場所

パスワード・メモ・サブスク・買い物リスト・タスク・予定などのデータは `%APPDATA%\TealSuite` に保存されます。アプリのフォルダを入れ替えても消えません。
Teal Hub の「その他 ▾」→「すべてのアプリのデータをバックアップ…」で、まとめて 1 つの zip に保存できます (Teal Pass と Teal Clip は暗号化されたまま入るので、同じ Windows ユーザーでしか開けません)。
Teal Hub がインターネットに送るのは「最新のリリースを教えて」という問い合わせ (GitHub) だけです。
