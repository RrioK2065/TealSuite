TealSuite (ティール スイート)  v1.5.0
==========================================

このフォルダには、Windows 用の小さなアプリが入っています。
インストールは不要です。フォルダごと好きな場所 (例: ドキュメント や デスクトップ) に置いて使ってください。

  TealHub.exe ……………… Teal Hub — アプリ管理 (ここから全部のアプリを起動・終了できます)
  apps\TealPass\ ………… Teal Pass — パスワード管理
  apps\TealMemo\ ………… Teal Memo — メモ
  apps\TealClip\ ………… Teal Clip — コピー履歴 (常駐)
  apps\TealVolume\ ……… Teal Volume — 音量操作 (常駐)
  TealUpdater.exe ………… アップデート用 (Teal Hub から呼ばれます。直接開く必要はありません)
  apps.json ……………… アプリの一覧 (Teal Hub が読み込みます。消さないでください)

動作に必要なもの: Windows 10 / 11 (.NET Framework 4.5 以上。Windows に最初から入っています)


■ はじめに (1 回だけ)
------------------------------------------
1. zip のまま開かずに、まず「ブロックの解除」をします。
   TealSuite.zip を右クリック →「プロパティ」→ 下の方の「セキュリティ: 許可する」にチェック →「OK」
   (これをしないと、起動のたびに警告が出ることがあります)
2. zip を右クリック →「すべて展開」で好きな場所に展開します。
3. TealHub.exe をダブルクリックして起動します。

● 「Windows によって PC が保護されました」と青い画面が出たとき
   自分で作ったアプリなので、署名がなく警告が出ます。
   「詳細情報」をクリック →「実行」で起動できます。(アプリごとに最初の 1 回だけ)

● よく使うアプリはショートカットを作ると便利です
   exe を右クリック →「その他のオプションを確認」→「送る」→「デスクトップ (ショートカットを作成)」
   スタートメニューやタスクバーにピン留めすることもできます。

● Windows の起動時に自動で起動したいとき (スタートアップ)
   Teal Hub の各アプリのカードにある「スタートアップ」スイッチをオンにします。
   (オンのときはテーマカラーになります。もう一度押すとオフ)
   ・Teal Hub 自身も、上の「スタートアップ」スイッチで自動で起動できます。
   ・Teal Clip と Teal Volume は「設定」の「Windows の起動時に自動で起動する」でも
     切り替えられます (Teal Hub のスイッチと同じ設定です)。
   ・自動で起動したときは、画面を出さずに静かに起動します
     (Teal Clip・Teal Volume は通知領域のアイコンだけ、ほかのアプリは最小化した状態)。
   ・TealSuite フォルダを別の場所へ移したときは、カードに「登録先が違います」と出ます。
     「登録し直す」を押すと、今の場所で登録し直します。
   ・Windows の「設定」→「アプリ」→「スタートアップ」でオフにした場合は、カードに表示されます。
     「有効に戻す」で元に戻せます。
   ・以前の ClipboardHistory.exe の自動起動が残っていると、Teal Hub の上にお知らせが出ます。
     「Teal Clip に置き換える」を押すと、古い自動起動を外して Teal Clip を登録します
     (押すまでは何も変えません。外したショートカットは消さずに
      %APPDATA%\TealSuite\TealHub\removed-startup フォルダへ移します)。
   うまくいかないときの代わりの方法:
   Win + R →「shell:startup」と入力して Enter → 開いたフォルダに
   exe のショートカットを入れても自動で起動できます。
   (この方法とスイッチを両方使うと 2 回起動しようとしますが、2 つ目はすぐ終わります)


■ Teal Hub — アプリ管理 (TealHub.exe)
------------------------------------------
・各アプリの「起動」「終了」ボタンで操作します。状態は「実行中 / 停止中」で表示されます。
・「終了」はまずアプリに終了をお願いし (保存してから閉じます)、応答がないときだけ
  確認のうえ強制終了します。
・「すべて終了」で、動いているアプリをまとめて終了します。
  (Teal Clip・Teal Volume が通知領域に隠れているときも、きちんと終了します)
・F5 / 「再読み込み」… アプリの一覧 (apps.json) を読み込み直します。
・Teal Hub も通知領域 (画面右下) に常駐します。Alt + H でどこからでも画面を開き、
  もう一度 Alt + H で隠します。ウィンドウの × を押しても終了せず、通知領域に隠れます。
  やめるときはアイコンを右クリック →「終了」。
・各カードに、アプリのバージョンとショートカットが表示されます。


■ ショートカット (全体ショートカット)
------------------------------------------
どのアプリにもショートカットを登録できます。登録しなくてもかまいません。
・カードの「変更」(なしのときは「登録」) → 欄をクリックして新しいキーを押す →「保存」。
・カードの「解除」で、ショートカットなしにできます (「なし」も正しい設定として覚えます)。
・「ショートカット一覧」ボタンで、全アプリのショートカットをまとめて確認・変更・解除できます。
・初期設定: Teal Hub を開く Alt + H / Teal Clip の呼び出し Ctrl + Shift + V /
  Teal Volume を開く Alt + V / Teal Pass・Teal Memo はなし。
・アプリを「開く」ショートカット (Teal Pass・Teal Memo など) は Teal Hub が受け持ちます。
  押すと、起動していなければ起動し、起動中なら前面に出します。
  Teal Hub が起動している間だけ使えるので、Teal Hub のスタートアップをオンにしておくと便利です。
・Teal Clip・Teal Volume のショートカットはそのアプリ自身が受け持ちます。
  Teal Hub で変えても、各アプリの「設定」で変えても同じ設定です (すぐに反映されます)。
・同じ組み合わせは 2 つに割り当てられません (割り当て済みのときは、どこで使っているかを表示します)。
  Ctrl + C や Alt + F4 など、よく使う操作と同じものは選べません。


■ Teal Pass — パスワード管理
------------------------------------------
・左側でパスワードを作り、「保存…」でサイト名・URL・ユーザー名 / ID・メモと一緒に保管できます。
・長さのスライダーは Shift を押しながらドラッグすると 4 文字ずつ動きます。
・コピーしたパスワードは約 30 秒後にクリップボードから自動で消えます。
・保存データは Windows のユーザーアカウントで暗号化されます (DPAPI)。
  → このPC・このユーザーでログインしているときだけ読めます。別のPCにコピーしても開けません。
  ショートカット: Ctrl+N 追加 / Ctrl+F 検索 / F5 再生成 / Enter 編集 / Delete 削除
                  一覧で Ctrl+C パスワードをコピー / Ctrl+B ユーザー名をコピー
                  編集画面で Ctrl+Enter 保存

■ Teal Memo — メモ
------------------------------------------
・入力した内容は自動で保存されます。
・以前の「メモアプリ」のメモは、初めて起動したときに自動で引き継ぎます
  (元のファイル %APPDATA%\MemoApp\notes.json は消さずに残します)。
  ショートカット: Ctrl+N 新規 / Ctrl+S すぐ保存 / Ctrl+F 検索 / Ctrl+Delete 削除

■ Teal Clip — コピー履歴
------------------------------------------
・起動すると画面右下 (タスクバーの通知領域) に常駐し、コピーした文字を 10 件まで記録します。
  ウィンドウを閉じても常駐し続けます。やめるときはトレイアイコンを右クリック →「終了」。
・Ctrl + Shift + V で履歴を呼び出します。
  1〜9・0 キー、または ↑↓ と Enter で選ぶと、その文字を貼り付けます。Esc で閉じます。
・呼び出しのショートカットは「設定」で変えられます (欄をクリックして新しいキーを押す →「保存」)。
  Ctrl・Alt・Win のどれかと文字・数字・F キーの組み合わせが使えます (例: Ctrl + Shift + V、Alt + C)。
  Ctrl + C や Alt + F4 など、よく使う操作と同じものは選べません。
・よく使う文字は「ピン留め」すると、新しくコピーしても消えません (最大 9 件)。
・パスワードマネージャーなどが「履歴に残さない」と指定したコピーは記録しません。
・履歴も DPAPI で暗号化して保存します。
  ショートカット (履歴の画面): Enter / Ctrl+C コピー / Ctrl+P ピン留め / Delete 削除

■ Teal Volume — 音量操作
------------------------------------------
・Windows の「音量ミキサー」と同じように、アプリごとの音量を変えられます。
・起動すると通知領域 (画面右下) に常駐します。
  Alt + V で画面を開き、もう一度 Alt + V (または Esc) で隠します。
  通知領域のアイコンをクリックしても開閉できます。
・ウィンドウの × を押しても終了せず、通知領域に隠れます (最初の 1 回だけお知らせが出ます)。
  やめるときはアイコンを右クリック →「終了」(Teal Hub の「終了」でも終わります)。
・アイコンの右クリックメニュー:「開く」「設定…」「終了」
・「設定」(画面上の「設定」ボタンか、アイコンの右クリック) で、開くショートカットと
  スタートアップを変えられます。ショートカットの決まりは Teal Clip と同じです。
  ほかのアプリが同じキーを使っていて登録できないときは、設定画面とお知らせで表示します。
  (Alt + V は、ほかのアプリのメニュー操作 Alt + V より優先されます。困るときは別のキーに)
・ウィンドウの位置と大きさは覚えておき、次に開いたときも同じ場所に出ます。
・スライダーをドラッグすると 1% ずつ、Shift を押しながらドラッグすると 5% ずつ動きます。
・スピーカーのボタンでミュート / 解除。上の「全体の音量」は既定の出力デバイスの音量です。
・音を出したことがあるアプリだけが表示されます。出てこないときは一度音を鳴らして F5 / 「更新」。
・Windows の通知音などは「システム音」として表示されます。
  ショートカット: Alt + V 開く / 隠す (どこからでも) / Esc 隠す / F5 更新


■ データの保存場所
------------------------------------------
  %APPDATA%\TealSuite\<アプリの ID>\
  (エクスプローラーのアドレス欄に %APPDATA%\TealSuite と入力すると開けます)

  TealPass\vault.dat     … パスワード (暗号化。1 つ前の版を vault.bak に保存)
  TealMemo\notes.json    … メモ
  TealClip\history.dat   … コピー履歴 (暗号化)
  settings.json / window.json など … 設定やウィンドウの位置・大きさ

・アプリのフォルダを新しい版に置き換えても、データはそのまま残ります。
・バックアップしたいときは %APPDATA%\TealSuite フォルダごとコピーしてください。
  (Teal Pass と Teal Clip のデータは、同じPC・同じユーザーでしか読めません)


■ 以前の版 (AppSuite 1.0) から移るとき
------------------------------------------
1.1 で名前が「Teal ○○」に変わりました (アプリ管理 → Teal Hub、PasswordMaker → Teal Pass、
メモ → Teal Memo、コピー履歴 → Teal Clip、ボリューム操作 → Teal Volume)。
1. 古いアプリ管理で「すべて終了」→ アプリ管理も閉じる
   (コピー履歴は通知領域のアイコンを右クリック →「終了」)
2. この TealSuite フォルダを好きな場所に置き、TealHub.exe から各アプリを起動
3. 各アプリは初めて起動したとき、%APPDATA%\AppSuite\<旧名>\ のデータ (パスワード・メモ・
   コピー履歴・設定) を %APPDATA%\TealSuite\<新しい ID>\ に自動でコピーして使います。
   ・元の %APPDATA%\AppSuite フォルダは消さずに残します (念のためのバックアップになります)。
   ・引き継いだフォルダには migrated-from.txt (引き継ぎ元の記録) ができます。
   ・新しい側にすでにデータがあるときは、上書きしません。
4. 動作を確認できたら、古い AppSuite フォルダ (exe のあるほう) は消してかまいません。
   スタートアップに ClipboardHistory.exe を入れていた場合は、Teal Hub の上に出るお知らせの
   「Teal Clip に置き換える」を押してください (ほかのアプリも同じように置き換えられます)。


■ 新しいバージョンのお知らせ (1.5.0 以降)
------------------------------------------
Teal Hub は、新しいバージョンが公開されていないかを 1 日 1 回確認します。
(公開場所: https://github.com/RrioK2065/TealSuite/releases)
・新しいバージョンがあると、Teal Hub の画面の上にお知らせが出て、「アップデート ▾」のボタンが
  「● 1.6.0 ▾」のように変わります (通知領域にもバージョンごとに 1 回だけお知らせします)。
・「内容を見る」で変更点を読めます。「今すぐアップデート」を押すとダウンロードして、
  いつもの確認画面 (下の「アップデート」の 3. から) が出ます。「あとで」でお知らせを閉じられます。
・すぐに確認したいとき: 「アップデート ▾」→「更新を確認」(通知領域のアイコンの右クリックにもあります)。
・確認しないようにするとき: 「アップデート ▾」→「自動で更新を確認する (1 日 1 回)」のチェックを外します。
  (チェックを外しても「更新を確認」は使えます)
・ダウンロードしたファイルは、公開されている確認用の値 (sha256) と照らし合わせ、
  github.com からの HTTPS 以外では受け取りません。インターネットにつながらないときは何も表示しません。
・送るのは「最新のリリースを教えて」という問い合わせだけです。データや利用状況は送りません。


■ アップデート (1.4.0 以降)
------------------------------------------
1.4.0 からは、フォルダを入れ替えなくても、アップデート ファイルで新しい版にできます。
(1.5.0 からは上の「お知らせ」から自動でダウンロードできます。ここは手動でファイルを使うときの手順です)
1. アップデート ファイル (TealSuite-update-x.y.z.tealupdate。リリース ページにあります) を受け取ります。
2. ファイルをダブルクリックするか、Teal Hub の画面にドラッグします。
   (Teal Hub の「アップデート ▾」→「アップデート ファイルを開く…」でも開けます)
3. 変わる内容 (アプリごとに 古いバージョン → 新しいバージョン、新しいアプリ) を確認して
  「アップデート」を押します。
4. 起動中のアプリはいったん終了し、ファイルを置き換えたあと自動で起動し直します。
   新しいアプリは Teal Hub に自動で追加されます。
・ファイルが壊れていたり途中で失敗したときは、何も変えずに元の状態に戻します。
・置き換える前のファイルは TealSuite フォルダ内の backup フォルダに残ります。
  うまく動かないときは「アップデート ▾」→「前のバージョンに戻す…」で戻せます。
・パスワードやメモなどのデータ (%APPDATA%\TealSuite) には一切触れません。
・今より古い版のファイルや、作り手が違うファイルは入れられません。
・.tealupdate の関連付けは Teal Hub を起動したときに自動で登録されます (このユーザーだけ。管理者権限は不要)。


■ 1.3 以前から 1.4.0 にするとき (最後のフォルダの入れ替え)
------------------------------------------
アップデートのしくみ (TealUpdater.exe) は 1.4.0 で入ったため、1.4.0 にするときだけは
今までどおりフォルダの中身を入れ替えます。次の版からはアップデート ファイルで更新できます。
1. Teal Hub で「すべて終了」→ Teal Hub も閉じる
2. 新しい TealSuite フォルダの中身で、古いフォルダの中身を上書き
   (データは %APPDATA% にあるので消えません。ショートカットの設定も引き継がれます)
