TealSuite (ティール スイート)  v1.9.0
==========================================

このフォルダには、Windows 用の小さなアプリが入っています。
インストールは不要です。フォルダごと好きな場所 (例: ドキュメント や デスクトップ) に置いて使ってください。

  TealHub.exe ……………… Teal Hub — アプリ管理 (ここから全部のアプリを起動・終了できます)
  apps\TealPass\ ………… Teal Pass — パスワード管理
  apps\TealMemo\ ………… Teal Memo — メモ
  apps\TealClip\ ………… Teal Clip — コピー履歴
  apps\TealVolume\ ……… Teal Volume — 音量操作
  apps\TealWallet\ ……… Teal Wallet — サブスク＆買い物リスト (1.9.0 で Teal Sub から名前が変わりました)
  apps\TealTasks\ ………… Teal Tasks — タスク管理＆カレンダー (1.7.0 から)
  TealUpdater.exe ………… アップデート用 (Teal Hub から呼ばれます。直接開く必要はありません)
  apps.json ……………… アプリの一覧 (Teal Hub が読み込みます。消さないでください)

動作に必要なもの: Windows 10 / 11 (.NET Framework 4.5 以上。Windows に最初から入っています)


■ はじめに (1 回だけ)
------------------------------------------
1. zip のまま開かずに、まず「ブロックの解除」をします。
   TealSuite.zip を右クリック →「プロパティ」→ 下の方の「セキュリティ: 許可する」にチェック →「OK」
   (これをしないと、起動のたびに警告が出ることがあります)
2. zip を右クリック →「すべて展開」で好きな場所に展開します。
3. TealHub.exe をダブルクリックして起動します。

● 「Windows によって PC が保護されました」と青い画面が出たとき
   自分で作ったアプリなので、署名がなく警告が出ます。
   「詳細情報」をクリック →「実行」で起動できます。(アプリごとに最初の 1 回だけ)

● よく使うアプリはショートカットを作ると便利です
   exe を右クリック →「その他のオプションを確認」→「送る」→「デスクトップ (ショートカットを作成)」
   スタートメニューやタスクバーにピン留めすることもできます。

● Windows の起動時に自動で起動したいとき (スタートアップ)
   Teal Hub で、そのアプリのカードの「⚙ 設定」→「スタートアップ」のスイッチをオンにします。
   (オンのときはテーマカラーになります。もう一度押すとオフ)
   ・スタートアップは「常駐」がオンのアプリだけ選べます (下の「常駐」を参照)。
   ・Teal Hub 自身は、上の「Teal Hub」の行の「⚙ 設定」から切り替えます。
     ショートカットは Teal Hub が受け付けるので、Teal Hub もオンにしておくのがおすすめです。
   ・自動で起動したときは、画面を出さずに通知領域 (画面右下) のアイコンだけで静かに待ちます。
   ・TealSuite フォルダを別の場所へ移したときは、設定画面に「登録先が違います」と出ます。
     「登録し直す」を押すと、今の場所で登録し直します。
   ・Windows の「設定」→「アプリ」→「スタートアップ」でオフにした場合は、設定画面に表示されます。
     「有効に戻す」で元に戻せます。
   ・以前の ClipboardHistory.exe の自動起動が残っていると、Teal Hub の上にお知らせが出ます。
     「Teal Clip に置き換える」を押すと、古い自動起動を外して Teal Clip を登録します
     (押すまでは何も変えません。外したショートカットは消さずに
      %APPDATA%\TealSuite\TealHub\removed-startup フォルダへ移します)。
   うまくいかないときの代わりの方法:
   Win + R →「shell:startup」と入力して Enter → 開いたフォルダに
   exe のショートカットを入れても自動で起動できます。
   (この方法とスイッチを両方使うと 2 回起動しようとしますが、2 つ目はすぐ終わります)


■ Teal Hub — アプリ管理 (TealHub.exe)
------------------------------------------
・各アプリの「起動」「終了」ボタンで操作します。状態は「実行中 / 停止中」で表示されます。
・「終了」はまずアプリに終了をお願いし (保存してから閉じます)、応答がないときだけ
  確認のうえ強制終了します。
・「すべて終了」で、動いているアプリをまとめて終了します。
  (Teal Clip・Teal Volume が通知領域に隠れているときも、きちんと終了します)
・F5 / 「再読み込み」… アプリの一覧 (apps.json) を読み込み直します。
・Teal Hub は常に通知領域 (画面右下) に常駐します。Alt + H でどこからでも画面を開き、
  もう一度 Alt + H で隠します。ウィンドウの × を押しても終了せず、通知領域に隠れます。
  やめるときはアイコンを右クリック →「終了」。
・各カードに、アプリのバージョン・ショートカット・常駐・スタートアップが表示されます。
・各カードの「⚙ 設定」を押すと、画面がそのアプリの設定に切り替わります。
  「← 戻る」(または Esc) で一覧に戻ります。設定できるのは次の 3 つです。
    ショートカット / 常駐 / スタートアップ
・各アプリの「設定」ボタン (Teal Clip・Teal Volume の画面や通知領域のメニュー) からも、
  Teal Hub のこの設定画面が開きます。
・「その他 ▾」(1.8.0 から)
    更新内容を見る … 今のバージョンで変わったこと (アップデートのあと 1 回だけお知らせも出ます)
    すべてのアプリのデータをバックアップ … %APPDATA%\TealSuite の中身を 1 つの zip に保存します。
      データ フォルダーの外 (ドキュメントや USB メモリなど) を選んでください。
    バックアップから復元 … 中身 (作成日時・ファイルの数) を見てから上書きします。
      動いているアプリは先に終了します。今のデータは復元の前に自動で backups フォルダーに残します。
      Teal Pass の保管庫と Teal Clip の履歴は、バックアップしたときと同じ Windows ユーザーでないと開けません。
    データ フォルダーを開く
・通知領域のアイコンを右クリック →「アプリを開く」から、各アプリを直接開けます。


■ ショートカット (全体ショートカット)
------------------------------------------
どのアプリにもショートカットを登録できます。登録しなくてもかまいません。
・「⚙ 設定」→ ショートカットの欄をクリック → 使いたいキーを押す →「登録」。
・「解除」で、ショートカットなしにできます (「なし」も正しい設定として覚えます)。
・初期設定: Teal Hub を開く Alt + H / Teal Clip の呼び出し Ctrl + Shift + V /
  Teal Volume を開く Alt + V / Teal Pass・Teal Memo はなし。
  変えたあとは「初期設定に戻す」で元に戻せます。
・ショートカットはすべて Teal Hub が受け付けます。
  押すと、アプリが起動していなければ Teal Hub が起動し、起動中なら呼び出します。
  Teal Hub が起動している間だけ使えるので、Teal Hub のスタートアップをオンにしておくと便利です。
・同じ組み合わせは 2 つに割り当てられません (どのアプリで使っているかを表示します)。
  ほかのソフトが使っているキーも登録できません (理由を表示して、前のキーのままにします)。
  Ctrl + C や Alt + F4 など、よく使う操作と同じものは選べません。
・Ctrl・Alt・Win のどれかと、文字・数字・F キーを組み合わせます (例: Ctrl + Shift + V、Alt + C)。
  Alt + 文字は、ほかのアプリのメニュー操作 (Alt + V など) より優先されます。困るときは別のキーに。
・1.5.0 で設定したショートカットはそのまま引き継ぎます。


■ 常駐 (×で閉じても通知領域に残す)
------------------------------------------
アプリごとに「⚙ 設定」→「常駐する」で選べます。
・オン: ウィンドウの × を押しても終了せず、通知領域 (画面右下) に隠れます (最初の 1 回だけお知らせ)。
  やめるときはアイコンを右クリック →「終了」(Teal Hub の「終了」「すべて終了」でも終わります)。
・オフ: × で閉じると終了します。ショートカットを押すと、Teal Hub がもう一度起動します。
・初期設定: Teal Clip・Teal Wallet・Teal Tasks がオン (起動している間だけ記録・お知らせができるため)。ほかはオフ。
  1.5.0 でスタートアップに登録していたアプリはオンとして引き継ぎます。
・Teal Hub は常に常駐します (全アプリのショートカットを受け付けるため)。


■ Teal Pass — パスワード管理
------------------------------------------
・左側でパスワードを作り、「保存…」でサイト名・URL・ユーザー名 / ID・メモと一緒に保管できます。
・長さのスライダーは Shift を押しながらドラッグすると 4 文字ずつ動きます。
・コピーしたパスワードは約 30 秒後にクリップボードから自動で消えます。
・保存データは Windows のユーザーアカウントで暗号化されます (DPAPI)。
  → このPC・このユーザーでログインしているときだけ読めます。別のPCにコピーしても開けません。
・★ お気に入り: よく使うものに印をつけて、「★ お気に入り」で絞り込めます。
・パスワードを変えて保存すると、以前のパスワードを 5 件まで残します (編集画面の「以前のパスワード」)。
・「その他 ▾」→「安全チェック…」: 使い回し・弱い・1 年以上変えていないパスワードを一覧にします。
  見つかったものは一覧の「要注意」で絞り込めます。
・「その他 ▾」→「ブラウザーの CSV から読み込む…」: Chrome・Edge・Firefox で書き出したパスワードを取り込みます。
  同じサイト・ID・パスワードのものはとばします。読み込んだあとは CSV ファイルを必ず削除してください。
・「その他 ▾」→「CSV に書き出す…」: 暗号化されていないファイルになります。移し終えたら必ず削除してください。
  ショートカット: Ctrl+N 追加 / Ctrl+F 検索 / F5 再生成 / Enter 編集 / Delete 削除
                  一覧で Ctrl+C パスワードをコピー / Ctrl+B ユーザー名をコピー
                  編集画面で Ctrl+Enter 保存

■ Teal Memo — メモ
------------------------------------------
・入力した内容は自動で保存されます。
・以前の「メモアプリ」のメモは、初めて起動したときに自動で引き継ぎます
  (元のファイル %APPDATA%\MemoApp\notes.json は消さずに残します)。
・ピン留め (Ctrl+P): 大事なメモを一覧のいちばん上に固定します。
・タグ: 本文に「#買い物」のように書くと、一覧の上の切り替え (すべて / ピン留め / #タグ / ゴミ箱) で絞り込めます。
・削除したメモはゴミ箱に入り、30 日以内なら「元に戻す」で戻せます (30 日たつと自動で消えます)。
・「その他 ▾」: .txt の読み込み / このメモを .txt に書き出す / すべてのメモをフォルダーに書き出す /
  文字の大きさ (小・中・大・特大) / ゴミ箱を空にする
  ショートカット: Ctrl+N 新規 / Ctrl+S すぐ保存 / Ctrl+F 検索 / Ctrl+Delete ゴミ箱へ / Ctrl+P ピン留め

■ Teal Clip — コピー履歴
------------------------------------------
・起動している間、コピーした文字を記録します (初期設定は 10 件。「記録の設定」で 20・30・50 件にもできます)。
  初期設定では常駐オンなので、ウィンドウを閉じても通知領域に残って記録を続けます。
  やめるときはトレイアイコンを右クリック →「終了」。
・Ctrl + Shift + V で履歴を呼び出します。
  1〜9・0 キー、または ↑↓ と Enter で選ぶと、その文字を貼り付けます。Esc で閉じます。
・呼び出しのショートカット・常駐・スタートアップは「設定」で変えられます
  (Teal Hub の設定画面が開きます)。
・よく使う文字は「ピン留め」すると、新しくコピーしても消えません (記録する件数 − 1 件まで)。
・「＋ 定型文」: あいさつや住所など、よく使う文を登録します (ピン留めとして上に並びます)。
・履歴の画面の上の欄で検索できます (Ctrl+F)。「編集」で記録した文字を書き換えられます。
・「その他 ▾」→「記録の設定…」: 記録する件数 / 古い履歴の自動削除 (1・7・30・90 日。ピン留めは消えません) /
  記録しない言葉 / パスワードらしい文字を記録しない、を選べます。
・「記録を一時停止」: 見られたくない文字をコピーするあいだ、記録を止めます (通知領域のメニューからも。次に起動したときは記録に戻ります)。
・パスワードマネージャーなどが「履歴に残さない」と指定したコピーは記録しません。
・履歴も DPAPI で暗号化して保存します。
  ショートカット (履歴の画面): Enter / Ctrl+C コピー / Ctrl+P ピン留め / Delete 削除

■ Teal Volume — 音量操作
------------------------------------------
・Windows の「音量ミキサー」と同じように、アプリごとの音量を変えられます。
・Alt + V で画面を開き、もう一度 Alt + V (または Esc) で隠します
  (起動していなければ Teal Hub が起動します)。
・初期設定では常駐オフなので、× で閉じると終了します。
  「常駐する」をオンにすると、× で閉じても通知領域 (画面右下) に隠れ、
  アイコンのクリックでも開閉できます (右クリックメニュー:「開く」「設定…」「終了」)。
・「設定」で、開くショートカット・常駐・スタートアップを変えられます (Teal Hub の設定画面が開きます)。
・ウィンドウの位置と大きさは覚えておき、次に開いたときも同じ場所に出ます。
・スライダーをドラッグすると 1% ずつ、Shift を押しながらドラッグすると 5% ずつ動きます。
・スピーカーのボタンでミュート / 解除。上の「全体の音量」は既定の出力デバイスの音量です。
・音を出したことがあるアプリだけが表示されます。出てこないときは一度音を鳴らして F5 / 「更新」。
・Windows の通知音などは「システム音」として表示されます。
・「プリセット ▾」(1.8.0 から): 今のアプリごとの音量を「会議」「ゲーム」などの名前で保存し (12 個まで)、
  あとで選ぶだけで同じ音量にできます。起動していないアプリはとばします。
・「すべてミュート」: 音を出しているアプリをまとめてミュート / 解除します (全体の音量はそのまま)。
・アプリの行を右クリック →「いちばん上に固定」「一覧から隠す」。隠したアプリは「その他 ▾」→「隠したアプリも表示」で戻せます。
  ショートカット: Alt + V 開く / 隠す (どこからでも) / Esc 隠す / F5 更新


■ Teal Wallet — サブスク＆買い物リスト (1.8.0 までの Teal Sub)
------------------------------------------
・動画・音楽・クラウドなど、毎月や毎年お金がかかっているサービスと、ふだんの買い物をまとめて管理します。
  タブ: ダッシュボード / サブスク / 見直し候補 / 解約済み / 買い物リスト / 欲しいもの (Ctrl+1〜6)
・1.8.0 から 1.9.0 にアップデートすると、Teal Sub のデータ・ショートカット・常駐・スタートアップの設定を
  そのまま引き継ぎます。古い TealSub.exe は閉じてから消し、Teal Hub の一覧も Teal Wallet に置き換えます。
  古いデータのフォルダ (%APPDATA%\TealSuite\TealSub) は念のため残します (消してもかまいません)。
  最初は「見本データを入れる」で、どんな画面になるか試せます (あとで削除できます)。
・ダッシュボード: 月あたり・1 年あたりの合計、次の支払い日、カテゴリ別の内訳。
  年払いは 12 で割り、週払いは 52 週 ÷ 12 か月で月あたりに直します。解約済みは合計に入れません。
・見直し候補: 次の点数の合計 (最大 100 点) が 30 点以上のものを出します。60 点以上は「見直しをおすすめ」。
    使う頻度「ほぼ使わない」+40 / 「月に数回」+20
    最後に使った日から 90 日以上 +35 / 45 日以上 +25 / 30 日以上 +15
    1 回あたりの金額が ¥1,000 以上 +25 / ¥400 以上 +12
    同じカテゴリにほかの契約がある (よく使う方は除く) +15
    無料期間が 7 日以内に終わる +25
  「今日使った」(Ctrl+U) で最後に使った日を記録すると、点数が正確になります。
・解約ガイド: 一般的な解約の手順 (iPhone / Android / 携帯会社払いを含む) を表示します。
  「編集」で自分で調べた解約ページの URL を登録すると、そこから開けます (http / https のみ)。
  このアプリはインターネットに接続せず、解約の操作もしません。
・お知らせ: 更新日と無料期間の終わりを 3 日前からお知らせします (「設定」で日数とオン・オフを変更)。
・支払い予定 (Ctrl+P、1.8.0 から): これから 12 か月、月ごとにいつ・どれにいくら払うかと、支払い方法ごとの金額を表示します。
・月の予算: 「設定」でサブスクに使ってよい金額 (月あたり) を決めると、ダッシュボードと支払い予定に
  あといくらか (超えていないか) を出します。0 にすると使いません。
・料金を変えて保存すると、料金の変更 (値上げ +○円 など) を記録します。
・「設定」から CSV に書き出し (Excel で開けます)、CSV から読み込み (すでにあるものはとばします)、
  バックアップ (JSON) と、バックアップから戻すができます。
  ショートカット: Ctrl+N 追加 / Ctrl+F 検索 / Ctrl+1〜6 タブ / Enter 編集 / Delete 削除 / Ctrl+U 今日使った /
                  Ctrl+P 支払い予定

・買い物リスト (1.9.0 から): 上の入力欄に書いて Enter で追加します。「、」で区切ると何品かまとめて入ります。
    牛乳 2 198円        → 牛乳・2 個・1 個 ¥198 (売り場は「乳製品・卵」と推測)
    卵 1パック 228      → 卵・1 パック・¥228
    トマト3個           → トマト・3 個
    ティッシュ #日用品  → 売り場「日用品」
  ・数字だけのときは 100 未満を数、100 以上を値段とみなします (「円」「¥」をつけると確実)。
  ・値段・売り場を書かなかったときは、前に買ったときの記録 (なければ名前からの推測) で埋めます。
  ・同じ名前の品がまだリストにあるときは、数を足してまとめます。
・リストは何個でも作れます (「リスト ▾」で追加・名前の変更・削除。Ctrl+PageUp / PageDown で切り替え)。
・品は売り場ごと (野菜・果物 → 肉・魚 → 豆腐・練り物 → … お店を回る順) に並びます。
  チェック (クリックか Space) した品は、下の「カゴに入れた」に移ります。
・右側に予想の合計・まだの分・カゴの中の分を出します。
  「買い物を終える…」(Ctrl+Enter) でレシートの合計を入れると、カゴの中の品を履歴に残してリストから消し、
  今月の買い物の金額に足します (予想との差も表示)。
・「チェック済みを消す」(Ctrl+Delete) は、履歴にも支出にも残さずにカゴの中の品だけ消します。
・よく買うもの: 入力欄の下にボタンで出ます (押すと前の数・値段・売り場で追加)。
  「履歴から…」(Ctrl+H) で前に買ったものを選んでまとめて追加できます。
・「テキストでコピー」(Ctrl+Shift+C): LINE やメモに貼れる形 (売り場ごと、カゴの中は ✓) でコピーします。
・月の予算: 「設定」の「買い物に使ってよい金額 (1 か月)」を決めると、買い物リストとダッシュボードに
  残りを出します。ダッシュボードにはサブスクと買い物を合わせた今月の支出の目安も出ます。
  ショートカット: Ctrl+L 入力欄へ / Space チェック / Enter 編集 / Delete 削除 / Ctrl+Enter 買い物を終える /
                  Ctrl+Delete チェック済みを消す / Ctrl+H 履歴から / Ctrl+Shift+C テキストでコピー /
                  Ctrl+PageUp・PageDown リストの切り替え / Ctrl+N 品を追加
・欲しいもの (1.9.0 から): すぐには買わないけれど欲しいものを、目標の値段・今の値段・優先度 (高・中・低)・
  メモつきで記録します。今の値段が目標以下になると「買いどき」と表示し、上に並べます。
  「買った…」(Ctrl+B) で買った値段を入れると、今月の買い物の金額に入ります。
  「買い物リストに入れる」で、今のリストに移せます。
  ショートカット: Ctrl+N 追加 / Enter 編集 / Delete 削除 / Ctrl+B 買った
・バックアップ (JSON) には買い物リストと欲しいものも入ります。1.8.0 のバックアップもそのまま戻せます。

■ Teal Tasks — タスク管理＆カレンダー
------------------------------------------
・上の入力欄に日本語で書いて Enter を押すと、読み取って登録します (Ctrl+Enter で確かめてから追加)。
    明日15時 歯医者 #病院            → 明日 15:00・タグ「病院」
    金曜までにレポート提出 重要 2時間 → 金曜まで・優先度 高・2 時間
    来週月曜 9:30 定例会議            → 来週の月曜 9:30
    毎週水曜 ジム 1時間半             → 毎週水曜・1 時間 30 分
    11月3日 午後2時半 打ち合わせ      → 11/3 14:30
    平日 9時 朝会                     → 月〜金の 9:00 にくり返し
    毎年 12/1 年賀状の準備            → 毎年 12/1
  ・読めるもの: 今日 / 明日 / あさって / ○日後 / 曜日 / 来週○曜 / 11/3・11月3日、
    15時・9:30・午後2時半・今夜、重要・急ぎ・優先度低、30分・2時間、#タグ、
    毎日・平日・毎週○曜・毎月・毎年
  ・「3時」のように 1〜6 時は午後 (15 時) とみなします。午前にしたいときは「午前3時」と書きます。
  ・時刻だけで、その時刻を今日もう過ぎているときは明日になります。
・今日: 期限切れと今日のタスクを「おすすめ順」に並べます。
  期限の近さ (期限切れ 100 点〜、今日 60 点、明日 35 点 …) + 優先度 (高 +30 / 中 +15) + すぐ終わるもの (+5〜10)。
  行の左の ○ をクリック (または Space) で完了。くり返しのタスクは、完了すると次の回ができます。
  「明日に回す」で期限を 1 日先へ。間違えたら Ctrl+Z で元に戻せます。
・カレンダー: 月・週・日。日の「＋」かダブルクリックで追加、ドラッグで日時を変更 (週・日は 15 分きざみ)。
  週は月曜はじまりです。
・一覧: 検索 (Ctrl+F) と絞り込み。統計: 最近 14 日の完了数、タグ別の内訳、今週の達成率。
・お知らせ: 時刻つきのタスクは 15 分前、その日のタスクは朝にまとめてお知らせします (「設定」で変更)。
・「その他 ▾」(1.8.0 から)
    テンプレートから追加 … 「選んでいるタスクをテンプレートにする…」で保存したもの (30 個まで) を
      期限 (何日後か)・時刻・優先度などごと追加します。
    まとめて追加… (Ctrl+Shift+N) … 1 行に 1 件ずつ書くと、まとめて登録します。
      行の頭の「・」「-」「1.」「[ ]」などは取りのぞき、「明日10時」などの書き方も読み取ります。
    選んでいるタスクを複製 (Ctrl+D)
    完了したタスクを整理 … 30 日 / 90 日 / 1 年より前に完了したものを削除します (Ctrl+Z で戻せます)。
・「設定」から CSV に書き出し、バックアップ (JSON) と、バックアップから戻すができます。
  ショートカット: Ctrl+L 入力欄へ / Ctrl+N 詳しく追加 / Ctrl+1〜4 タブ / Ctrl+F 検索 /
                  Space 完了 / Enter 編集 / Delete 削除 / Ctrl+Z 元に戻す /
                  Ctrl+Shift+N まとめて追加 / Ctrl+D 複製

※ Teal Wallet と Teal Tasks は AI もインターネットも使いません。
  お知らせは起動している間だけ出るので、初期設定で「常駐」がオンです (× で閉じても通知領域に残ります)。
  パソコンの起動時から動かすには、Teal Hub の「⚙ 設定」で「スタートアップ」をオンにしてください。
  ショートカットの初期設定はありません (Teal Hub の「⚙ 設定」で登録できます)。


■ データの保存場所
------------------------------------------
  %APPDATA%\TealSuite\<アプリの ID>\
  (エクスプローラーのアドレス欄に %APPDATA%\TealSuite と入力すると開けます)

  TealPass\vault.dat     … パスワード (暗号化。1 つ前の版を vault.bak に保存)
  TealMemo\notes.json    … メモ
  TealClip\history.dat   … コピー履歴 (暗号化)
  TealWallet\subs.json   … サブスク (1.8.0 までは TealSub\subs.json)
  TealWallet\shopping.json … 買い物リスト・欲しいもの・買い物の履歴
  TealTasks\tasks.json   … タスク
  settings.json / window.json など … 設定やウィンドウの位置・大きさ

・アプリのフォルダを新しい版に置き換えても、データはそのまま残ります。
・バックアップしたいときは %APPDATA%\TealSuite フォルダごとコピーしてください。
  (Teal Pass と Teal Clip のデータは、同じPC・同じユーザーでしか読めません)


■ 以前の版 (AppSuite 1.0) から移るとき
------------------------------------------
1.1 で名前が「Teal ○○」に変わりました (アプリ管理 → Teal Hub、PasswordMaker → Teal Pass、
メモ → Teal Memo、コピー履歴 → Teal Clip、ボリューム操作 → Teal Volume)。
1. 古いアプリ管理で「すべて終了」→ アプリ管理も閉じる
   (コピー履歴は通知領域のアイコンを右クリック →「終了」)
2. この TealSuite フォルダを好きな場所に置き、TealHub.exe から各アプリを起動
3. 各アプリは初めて起動したとき、%APPDATA%\AppSuite\<旧名>\ のデータ (パスワード・メモ・
   コピー履歴・設定) を %APPDATA%\TealSuite\<新しい ID>\ に自動でコピーして使います。
   ・元の %APPDATA%\AppSuite フォルダは消さずに残します (念のためのバックアップになります)。
   ・引き継いだフォルダには migrated-from.txt (引き継ぎ元の記録) ができます。
   ・新しい側にすでにデータがあるときは、上書きしません。
4. 動作を確認できたら、古い AppSuite フォルダ (exe のあるほう) は消してかまいません。
   スタートアップに ClipboardHistory.exe を入れていた場合は、Teal Hub の上に出るお知らせの
   「Teal Clip に置き換える」を押してください (ほかのアプリも同じように置き換えられます)。


■ 新しいバージョンのお知らせ (1.5.0 以降)
------------------------------------------
Teal Hub は、新しいバージョンが公開されていないかを 1 日 1 回確認します。
(公開場所: https://github.com/RrioK2065/TealSuite/releases)
・新しいバージョンがあると、Teal Hub の画面の上にお知らせが出て、「アップデート ▾」のボタンが
  「● 1.6.0 ▾」のように変わります (通知領域にもバージョンごとに 1 回だけお知らせします)。
・「内容を見る」で変更点を読めます。「今すぐアップデート」を押すとダウンロードして、
  いつもの確認画面 (下の「アップデート」の 3. から) が出ます。「あとで」でお知らせを閉じられます。
・すぐに確認したいとき: 「アップデート ▾」→「更新を確認」(通知領域のアイコンの右クリックにもあります)。
・確認しないようにするとき: 「アップデート ▾」→「自動で更新を確認する (1 日 1 回)」のチェックを外します。
  (チェックを外しても「更新を確認」は使えます)
・ダウンロードしたファイルは、公開されている確認用の値 (sha256) と照らし合わせ、
  github.com からの HTTPS 以外では受け取りません。インターネットにつながらないときは何も表示しません。
・送るのは「最新のリリースを教えて」という問い合わせだけです。データや利用状況は送りません。


■ アップデート (1.4.0 以降)
------------------------------------------
1.4.0 からは、フォルダを入れ替えなくても、アップデート ファイルで新しい版にできます。
(1.5.0 からは上の「お知らせ」から自動でダウンロードできます。ここは手動でファイルを使うときの手順です)
1. アップデート ファイル (TealSuite-update-x.y.z.tealupdate。リリース ページにあります) を受け取ります。
2. ファイルをダブルクリックするか、Teal Hub の画面にドラッグします。
   (Teal Hub の「アップデート ▾」→「アップデート ファイルを開く…」でも開けます)
3. 変わる内容 (アプリごとに 古いバージョン → 新しいバージョン、新しいアプリ) を確認して
  「アップデート」を押します。
4. 起動中のアプリはいったん終了し、ファイルを置き換えたあと自動で起動し直します。
   新しいアプリは Teal Hub に自動で追加されます。
・ファイルが壊れていたり途中で失敗したときは、何も変えずに元の状態に戻します。
・置き換える前のファイルは TealSuite フォルダ内の backup フォルダに残ります。
  うまく動かないときは「アップデート ▾」→「前のバージョンに戻す…」で戻せます。
・パスワードやメモなどのデータ (%APPDATA%\TealSuite) には一切触れません。
・今より古い版のファイルや、作り手が違うファイルは入れられません。
・.tealupdate の関連付けは Teal Hub を起動したときに自動で登録されます (このユーザーだけ。管理者権限は不要)。


■ 1.3 以前から 1.4.0 にするとき (最後のフォルダの入れ替え)
------------------------------------------
アップデートのしくみ (TealUpdater.exe) は 1.4.0 で入ったため、1.4.0 にするときだけは
今までどおりフォルダの中身を入れ替えます。次の版からはアップデート ファイルで更新できます。
1. Teal Hub で「すべて終了」→ Teal Hub も閉じる
2. 新しい TealSuite フォルダの中身で、古いフォルダの中身を上書き
   (データは %APPDATA% にあるので消えません。ショートカットの設定も引き継がれます)
